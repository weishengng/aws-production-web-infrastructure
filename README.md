# AWS Production Web Infrastructure

Production-style AWS infrastructure project designed to simulate the responsibilities of a junior cloud engineer or cloud operations engineer.

## Goals

* Deploy a Linux web server on AWS EC2
* Configure networking and security
* Implement monitoring and alerting
* Automate infrastructure with Terraform
* Document deployment and operational procedures

## Planned Architecture

Internet → Route 53 → EC2 (Nginx) → Application → S3 → CloudWatch/SNS
